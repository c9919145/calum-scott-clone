How saving works

Save writes your changes to this browser (applied immediately on the site).
Export JSON downloads a site.json — place it at data/site.json to publish those changes for every visitor.
Import loads a previously exported file back into the editor.
Reset restores the original Calum Scott clone content.

Publish to GitHub Pages

Uploads data/site.json to your repo so every visitor sees your current edits. Deploy takes about a minute. Your details are stored only in this browser (localStorage), never in the published files.
